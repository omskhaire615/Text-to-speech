# Text-to-Speech

A small text-to-speech project: enter text and submit it to hear the text spoken aloud.

## What it does

- Accepts text entered by the user.
- Speaks the submitted text.

## How to try it

1. Open the project repository and review the source files.
2. Follow any setup instructions included with the project files.
3. Run the application and enter a short sentence to test speech output.
